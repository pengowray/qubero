What the scan depends on

everything above 0x17d · 381 B of tables for 611 KiB of data

Quantisation tables · DQT at 0x2

q0 for Y (fine, near-lossless: values 2–12) · q1 for Cb, Cr (coarser: 3–15). The coarse tail of both tables is a flat 12: high frequencies are heavily crushed, typical of a high-quality Adobe export. Open as 8×8 grids

Huffman tables · DHT at 0xb1

dc0 (11 symbols), dc1 (9), ac0 (60), ac1 (60). Shortest code 2 bits, longest 16. Code length histograms · full code tables

Frame header · SOF0 at 0x9e

1920 × 1200, 3 components, no subsampling. Everything the pixel grid needs; the scan header at 0x17d then binds each component to its tables.

Restart markers · DRI at 0x88

Every 240 MCUs the coder resets: 149 RST markers split the scan into independently decodable stripes of 16 pixel rows. They are the only landmarks inside the 611 KiB — the view uses them as its row grid. List all 149
